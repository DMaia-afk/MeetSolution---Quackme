Guia Técnico MeetSolution

Este guia detalha o funcionamento interno, requisitos de infraestrutura e otimizações para o MeetSolution, servindo como complemento técnico ao README oficial.

MeetSolution is a comprehensive tool for recording, transcribing, and summarizing meeting audio using advanced AI technologies. It leverages WhisperX for speaker diarization and transcription, and integrates with Ollama for generating structured summaries of meetings.

Por que WhisperX e Ollama?

Priorizamos soluções open-source e de custo zero: WhisperX roda localmente sem taxas; Ollama permite inferência local sem assinatura.

Why Choose WhisperX and Ollama?

We prioritize cost-effective open-source solutions: WhisperX runs locally with no API fees; Ollama enables local LLM inference avoiding subscription costs.

1. Requisitos de Software e Instalação

Python & FFmpeg

O Python 3.10+ é mandatório para suporte ao WhisperX. O FFmpeg deve estar instalado e nas variáveis de ambiente (PATH).

Ollama & Hugging Face

Instale o Ollama e realize o pull do modelo: ollama pull deepseek-r1:8b.

PowerShell / Terminal Setup Inicial 
# Clonar repositório
git clone https://github.com/DMaia-afk/MeetSolution---Quackme.git
cd MeetSolution---Quackme

# Criar e ativar ambiente virtual
python -m venv venv
.\venv\Scripts\activate

# Instalar dependências
pip install -r requirements.txt

Importante (Windows): Utilize sempre o PowerShell como Administrador para evitar erros de permissão.

Dicas de Ouro (Best Practices)

Posicionamento do Microfone

Mantenha o microfone a ~10-20cm da boca, em ângulo, e evite ruído de fundo direto.

Keep the mic ~10-20cm from your mouth, angled, and avoid direct background noise.

Como Falar para a IA Entender

Fale claro, pausadamente, e evite falar em conjunto com outros participantes.

Speak clearly, pause between speakers, and avoid talking over others.

Organização de Pastas

Salve áudios em inputs/, transcrições em outputs/transcripts/ e resumos em outputs/summaries/.

Save audio in inputs/, transcripts in outputs/transcripts/ and summaries in outputs/summaries/.

5. Otimização de Diarização

Batch Size

Aumente para 16 ou 32 se tiver muita VRAM para acelerar o processo.

VRAM Flush

O código limpa a memória da GPU automaticamente após cada uso.

6. Engenharia de Sumarização

Prompt & Modelo DeepSeek-R1

  • Foco em Ações: O sumário prioriza listas de tarefas (To-do lists).
  • Idioma: Configurado para responder sempre em Português.

7. Solução de Problemas Comuns

Erro de CUDA / Memória

Reduza o tamanho do modelo (ex: de Medium para Small) se o app travar ao iniciar a transcrição.
